# 🌸 AniLog 🌸

## 👋 About

Inspired by MyAnimeList, **AniLog** is simple and minimalistic. Discover the easiest way to track, manage, and organize your
anime watching experience regardless of whether you’re a casual viewer or a hardcore fan. Log your completed shows, keep
track of ongoing series, and explore the best the anime world has to offer.

## 💻 Tech Stack

- Spring Boot

- Spring Framework

- Spring Security

- PostgreSQL

- Thymeleaf

- Bootstrap 5

- Jikan API
